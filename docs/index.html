Compass Doc AI

학생부 PDF를 일괄 업로드해 JSON / db3 로 변환하는 Windows 데스크톱 앱.

⬇ Windows 설치 파일 다운로드
Windows 10/11 (64-bit) · 약 100 MB · 별도 Java 설치 불필요
  1. 위 버튼을 클릭해 Setup.exe 를 받습니다.
  2. 받은 파일을 더블클릭해 설치를 시작합니다.
  3. "Windows의 PC 보호" 경고가 뜨면 추가 정보 → 실행 을 클릭합니다.
  4. 설치 마법사 안내대로 진행합니다.
  5. 바탕화면 또는 시작메뉴의 "Compass Doc AI" 로 실행합니다.
SmartScreen 경고는 코드 서명 인증서가 없어서 표시되는 정상적인 안내입니다. 설치 파일은 GitHub 의 공식 릴리스 페이지에서 직접 받습니다.
